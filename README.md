# Uniswap swap morph

An interactive React motion study that follows the supplied Paper frames, with contrast adjustments, and adapts the measured-height technique from Jakub Krehel’s “Building an animated sign-in dialog.” Open the preselected USDC → ETH form, enter an amount, complete the readiness checklist, and continue through a simulated connected-wallet swap, review, authorization, progress, and receipt. Wallet details and transactions are illustrative fixtures; no blockchain action occurs.

```sh
pnpm install
pnpm dev
```

Run the full verification suite with `pnpm check`.
